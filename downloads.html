安装包

打开 Releases ，按系统下载最新文件：

  • Windows：Setup 安装包，或 portable zip
  • macOS：`.app` zip（也可 Homebrew，见下）
  • Linux：`linux-cli` tar.gz（命令行 + 内嵌网页）
  • Android：`full` 离线 APK（手机 / 平板 / 电视）

Windows 若提示缺少组件，安装 WebView2 后再开。

macOS Homebrew

brew tap lsuen/surdance && brew install --cask surdance-player

产品面向练舞，随便装、随便转。详细步骤见仓库 Releases README。
